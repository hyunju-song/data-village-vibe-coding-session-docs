# Linux 명령어 치트시트

> **OS 공통** — Mac 터미널, WSL(Ubuntu), Git Bash 어디서든 동일하게 동작합니다.

---

## 위치 확인 / 이동

| 명령어 | 하는 일 |
| --- | --- |
| `pwd` | 지금 내가 있는 폴더 경로 출력 |
| `ls` | 현재 폴더 안 파일·폴더 목록 |
| `ls -la` | 숨김 파일 포함, 권한·크기까지 상세 출력 |
| `cd 폴더이름` | 그 폴더 안으로 이동 |
| `cd ~` | 홈 폴더로 이동 (어디서든 기준점으로 돌아오기) |
| `cd ..` | 한 단계 위 폴더로 이동 |
| `cd -` | 바로 전에 있던 폴더로 이동 |

---

## 파일 / 폴더 다루기

| 명령어 | 하는 일 |
| --- | --- |
| `mkdir 폴더이름` | 새 폴더 만들기 |
| `mkdir -p a/b/c` | 중간 폴더까지 한 번에 만들기 |
| `touch 파일이름` | 빈 파일 만들기 |
| `cp 원본 사본` | 파일 복사 |
| `cp -r 원본폴더 사본폴더` | 폴더 통째로 복사 |
| `mv 원본 대상` | 파일·폴더 이동 또는 이름 바꾸기 |
| `rm 파일이름` | 파일 삭제 (복구 불가) |
| `rm -r 폴더이름` | 폴더 통째로 삭제 (복구 불가) |

> ⚠️ `rm`은 휴지통 없이 바로 지웁니다. 폴더 삭제 전에 `ls`로 내용을 먼저 확인하세요.

---

## 파일 내용 보기

| 명령어 | 하는 일 |
| --- | --- |
| `cat 파일이름` | 파일 전체 내용 출력 |
| `less 파일이름` | 페이지 단위로 보기 (끝내려면 `q`) |
| `head 파일이름` | 파일 앞 10줄만 출력 |
| `head -n 20 파일이름` | 앞 20줄 출력 |
| `tail 파일이름` | 파일 뒤 10줄만 출력 |
| `tail -f 파일이름` | 파일 내용이 추가될 때마다 실시간 출력 (로그 볼 때) |

## 검색

| 명령어 | 하는 일 |
| --- | --- |
| `grep "찾을단어" 파일이름` | 파일 안에서 단어가 포함된 줄 찾기 |
| `grep -r "찾을단어" 폴더이름` | 폴더 안 모든 파일에서 재귀 검색 |
| `grep -i "단어" 파일` | 대소문자 구별 없이 검색 |
| `find . -name "파일이름"` | 현재 폴더 아래에서 파일 이름으로 찾기 |
| `find . -name "*.py"` | 확장자로 찾기 (예: 모든 .py 파일) |

## 프로세스 / 기타

| 키 / 명령어 | 하는 일 |
| --- | --- |
| `Ctrl + C` | 실행 중인 프로세스 즉시 종료. 막혔을 때 탈출 |
| `Ctrl + Z` | 프로세스를 백그라운드로 보냄 (종료 아님) |
| `↑` (위쪽 화살표) | 이전에 입력한 명령어 불러오기 |
| `Tab` | 명령어·파일 이름 자동완성 (두 번 누르면 목록 표시) |
| `clear` | 터미널 화면 지우기 |
| `history` | 내가 입력한 명령어 전체 목록 보기 |
| `which 명령어` | 그 명령어가 어디 설치됐는지 경로 확인 (`which python3`) |
